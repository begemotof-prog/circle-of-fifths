# Круг квинт — Android-приложение

## Как получить APK (без программирования)
1. Зарегистрируйтесь на github.com и создайте новый репозиторий (можно приватный).
2. Загрузите в него все файлы из этой папки: Add file → Upload files.
   Если папка `.github` не загрузилась: Add file → Create new file, в имени файла введите
   `.github/workflows/build-apk.yml` и вставьте содержимое одноимённого файла.
3. Откройте вкладку Actions. Сборка стартует сама после загрузки (или Build APK → Run workflow).
   Она занимает 5–10 минут.
4. Когда появится зелёная галочка, откройте сборку и внизу в Artifacts скачайте `circle-of-fifths-apk`.
   Распакуйте архив: внутри `app-debug.apk`.
5. Перенесите APK на телефон и откройте его. Разрешите установку из этого источника.
   Play Protect может предупредить о неизвестном разработчике: это нормально для личной сборки.

## Что можно поменять
- Название и id приложения: `capacitor.config.json`.
- Содержимое: `www/index.html`. После правки загрузите файл в репозиторий, и APK соберётся заново.
- Иконка: `assets/icon-only.png`, `icon-foreground.png`, `icon-background.png` (1024×1024).
